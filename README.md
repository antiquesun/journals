# journals
Blog, video, photo web sharing site for private groups  and families in LAMP environment
The site is all contained within the main journals folder. 
Installation is straight forward by utilizing a LAMP based environment (download/install MAMP e.g.) and placing the contents of the journals folder either at the top of an htdocs location of the web server you are running or creating a sub-domain. Inside the data folder is a file called journals.sql that can be used to create the database and data associated with the blogs, galleries, images and videos. Be sure to have mod_rewrite on and place the .htaccess file at the top folder root location.
